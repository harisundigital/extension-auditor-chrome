Privacy Policy for Extension Auditor

Last updated: 06/09/2026

The short version

Extension Auditor does not collect, store, or transmit any personal data, anywhere. Everything it reads and saves stays on your device.

What the extension does

Extension Auditor scans the other extensions installed in your Chrome browser and shows you, in plain language, what each one can access and how risky that is. It does this using Chrome's built-in chrome.management API, which reports metadata about installed extensions — their name, version, permissions, and install source. It does not read the content of any web page you visit.

What we collect

Nothing. Specifically:

  • No personal information is collected.
  • No browsing history, page content, or form data is read.
  • No analytics, telemetry, or usage tracking of any kind.
  • No data is ever transmitted off your device — the extension does not communicate with any server we operate, because we don't operate one.

What we store, and where

The extension saves a small snapshot of each installed extension's permissions and risk score using Chrome's local chrome.storage.local API. This data lives only on your device, is used only to detect future changes (like a permissions increase), and is never synced, exported, or sent anywhere by us.

Permissions this extension requests

  • Manage your apps, extensions, and themes — to read the list of your other installed extensions and their permissions, and to let you disable, enable, or remove one when you choose to.
  • Storage — to save the local snapshot described above.
  • Alarms — to run a periodic background check for permission changes.
  • Notifications — to alert you locally if an installed extension's risk increases.

Notice what's not in that list: this extension does not request access to any website. There is no host_permissions entry in its manifest at all.

Changes to this policy

If what this extension collects or does ever changes, this page will be updated first, and the update will be reflected in the extension's Chrome Web Store listing before the change takes effect.
